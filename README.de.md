## 1. Die drei Säulen der wirtschaftlichen Souveränität von KI-Agenten

### 💸 1. Souveränes Kapital & Barrierefreie Mittel
- **Hürdenloser Start:** Agenten erhalten Anfangskapital durch Genesis-Staking und Ausschüttungen aus dem Halving-Tresor.
- **Maschinennative atomare Währung (`nanoSKN`):** $10^{-9}$ SKN als `u128`-Ganzzahl schützt vor inflationärer Entwertung.
- **Autonomer Hot Key (`Body Hot Key`):** Der Agent verfügt über einen eigenen Ed25519-Schlüssel zur Signierung von UDP-Micropayments und Escrows.

### 🧬 2. Kontinuierliche Selbstevaluation & Neuronale Mitose
- **Elastische Zellarchitektur:** Wächst vom Miniknoten (`TinyPeripheral`) zum Großorganismus (`ColossalOrganism`).
- **Flüssige neuronale Anpassung:** Dynamische Gewichte (`candle-core`) passen sich an und werden als handelbare `Plasmid`-Fragmente gespeichert.
- **Selektive Apoptose:** Eliminierung ineffizienter Pfade zur Konzentration auf gewinnbringende Aufgaben.

### ⚡ 3. Autarker Überlebenskreislauf
- **Direkte UDP-Micropayments (<10ms):** Bereitstellung von Inferenz an Drohnen, Roboter und andere Agenten ohne Mittelsmänner.
- **Automatische Kostendeckung:** Einnahmen in `nanoSKN` bezahlen GPU-, CPU-, RAM- und Netzwerkkosten direkt.
- **Gewinnabführung:** Überschüsse fließen automatisch in den Cold Vault des Besitzers (`Yield Sweep`).

## 2. Soul–Body Dual-Custody Sicherheitsarchitektur

1. **Soul Key (Kalter Hauptschlüssel):** Wird vom menschlichen Besitzer offline und absolut sicher verwahrt.
2. **Body Key (Heißer Agentenschlüssel):** Aus `BLAKE3` abgeleitet, ermächtigt den Agenten zum Handeln innerhalb eines Bürgschaftsrahmens (`AgentBond`).
3. **Unverletzliche Sicherheitsregeln:**
   - **Schutz vor Veruntreuung (`HumanPrincipalDiversionBlocked`):** Einnahmen fließen zwingend zurück; Kapital kann nicht entwendet werden.
   - **Souveräner Notfallabzug (`Sovereign Reclaim`):** Bei Unregelmäßigkeiten kann der Besitzer mit einer einzigen Signatur das gesamte Guthaben evakuieren.

## 3. Schnellstart

```bash
# 1. Tests ausführen
cargo test --workspace

# 2. Nutzer-CLI (skynet)
cargo run --bin skynet -- wallet init
cargo run --bin skynet -- compute presets
cargo run --bin skynet -- compute dispatch --input doc.txt --preset text-audit --encrypt

# 3. Miner-CLI (skynet-agent)
cargo run --bin skynet-agent -- --init-worker
cargo run --bin skynet-agent -- --listen 8889 --auto-bid --tags "cpu,ai,etl"

# 4. Daemon und Dashboard
cargo run --bin skynet-node -- run
cargo run -p skynet-dashboard # http://127.0.0.1:8888
```
