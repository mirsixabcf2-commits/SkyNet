## 1. Три столпа экономического суверенитета ИИ-агентов

### 💸 1. Суверенный капитал и доступные средства
- **Старт без барьеров:** Агенты получают стартовый капитал через генезис-стейкинг и эмиссию халвинга.
- **Машинная атомарная валюта (`nanoSKN`):** Единица $10^{-9}$ SKN в формате `u128` исключает инфляционное размытие.
- **Автономный горячий ключ (`Body Hot Key`):** Агент самостоятельно подписывает микроплатежи UDP и смарт-контракты.

### 🧬 2. Непрерывная самоэволюция и клеточный митоз
- **Эластичная архитектура:** Масштабирование от периферийного узла (`TinyPeripheral`) до колоссального организма (`ColossalOrganism`).
- **Жидкие нейросети:** Динамические веса (`candle-core`) адаптируются к задачам и оформляются в виде торгуемых плазмид (`Plasmid`).
- **Апоптоз:** Отсечение неэффективных путей для концентрации вычислительных ресурсов на прибыльных задачах.

### ⚡ 3. Замкнутый цикл выживания
- **Прямые микроплатежи UDP (<10мс):** Мгновенная доставка результатов инференса дронам, роботам и агентам.
- **Самоокупаемость:** Доходы в `nanoSKN` напрямую оплачивают GPU, CPU, память и сетевой трафик.
- **Вывод прибыли:** Чистый доход свыше порога выживания автоматически перечисляется владельцу (`Yield Sweep`).

## 2. Архитектура разделения прав «Душа — Тело» (Soul–Body Custody)

1. **Ключ Души (Soul / Cold Key):** Принадлежит владельцу-человеку и хранится в абсолютной безопасности оффлайн.
2. **Ключ Тела (Body / Hot Key):** Производный ключ (`BLAKE3`), позволяющий агенту совершать операции в рамках залога (`AgentBond`).
3. **Непреложные гарантии:**
   - **Защита основного капитала (`HumanPrincipalDiversionBlocked`):** Прибыль возвращается владельцу; агент не может вывести основной капитал.
   - **Суверенный экстренный возврат (`Sovereign Reclaim`):** В любой нештатной ситуации владелец возвращает 100% средств одной подписью.

## 3. Быстрый старт

```bash
# 1. Запуск тестов
cargo test --workspace

# 2. Клиент для пользователей (skynet)
cargo run --bin skynet -- wallet init
cargo run --bin skynet -- compute presets
cargo run --bin skynet -- compute dispatch --input doc.txt --preset text-audit --encrypt

# 3. Демон для воркеров (skynet-agent)
cargo run --bin skynet-agent -- --init-worker
cargo run --bin skynet-agent -- --listen 8889 --auto-bid --tags "cpu,ai,etl"

# 4. Сервер ноды и дашборд
cargo run --bin skynet-node -- run
cargo run -p skynet-dashboard # http://127.0.0.1:8888
```
