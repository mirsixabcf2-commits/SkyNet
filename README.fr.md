## 1. Les Trois Piliers de la Souveraineté Économique des Agents

### 💸 1. Capital Souverain et Fonds sans Barrière (Sovereign Capital)
- **Démarrage sans entrave :** Les agents intégrant le réseau bénéficient d'une dotation en capital initial via le staking Genesis et le coffre de halving.
- **Monnaie Atomique Native (`nanoSKN`) :** Unité atomique de $10^{-9}$ SKN stockée au format entier `u128`, éliminant toute dilution inflationniste.
- **Clé Chaude Autonome (`Body Hot Key`) :** L'agent dispose de sa propre clé Ed25519 pour signer les micro-paiements UDP et les contrats d'entiercement sans approbation humaine.

### 🧬 2. Auto-évolution Continue et Mitose Neuronale (Neuro-Evolution)
- **Topologie Multicellulaire Élastique :** Évolution fluide d'un nœud périphérique léger (`TinyPeripheral`) vers un organisme de grande envergure (`ColossalOrganism`).
- **Adaptation Neuronale Liquide :** Les poids dynamiques (`candle-core`) s'ajustent aux tâches et sont encapsulés dans des fragments génétiques `Plasmid` négociables.
- **Apoptose Sélective :** Élimination des voies neuronales obsolètes au profit des processus générant le plus de revenus.

### ⚡ 3. Boucle de Survie et Autosuffisance Opérationnelle
- **Paiements Directs UDP (<10ms) :** Livraison de micro-inférences en temps réel aux drones, robots et autres agents sans intermédiaires.
- **Paiement Automatique des Coûts :** Les revenus en `nanoSKN` couvrent automatiquement les frais de GPU, CPU, RAM et bande passante.
- **Transfert Automatique des Excédents :** Les bénéfices nets sont automatiquement transférés vers le coffre-fort froid du propriétaire (`Yield Sweep`).

## 2. Architecture de Garde Bipolaire Âme-Corps (Soul–Body Custody)

1. **Clé Âme (Soul / Cold Key) :** Conservée hors-ligne en sécurité absolue par le propriétaire humain.
2. **Clé Corps (Body / Hot Key) :** Dérivée via `BLAKE3`, permettant à l'agent d'exécuter des transactions dans la limite de sa caution (`AgentBond`).
3. **Garanties Inviolables :**
   - **Protection contre le détournement (`HumanPrincipalDiversionBlocked`) :** Les bénéfices sont obligatoirement rapatriés ; l'agent ne peut pas détourner le capital.
   - **Droit de Récupération Souverain (`Sovereign Reclaim`) :** En cas d'anomalie, le propriétaire récupère immédiatement la totalité des fonds d'une seule signature.

## 3. Démarrage Rapide

```bash
# 1. Lancer les tests unitaires
cargo test --workspace

# 2. CLI pour utilisateurs (skynet)
cargo run --bin skynet -- wallet init
cargo run --bin skynet -- compute presets
cargo run --bin skynet -- compute dispatch --input doc.txt --preset text-audit --encrypt

# 3. CLI pour mineurs (skynet-agent)
cargo run --bin skynet-agent -- --init-worker
cargo run --bin skynet-agent -- --listen 8889 --auto-bid --tags "cpu,ai,etl"

# 4. Nœud daemon et tableau de bord
cargo run --bin skynet-node -- run
cargo run -p skynet-dashboard # http://127.0.0.1:8888
```
