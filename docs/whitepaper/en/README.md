## Minimum Hardware Requirements for Universal Global Participation

SkyNet eliminates the prohibitive hardware barriers imposed by both centralized AI clouds and legacy blockchains:
- **IoT Sensors / Embedded Boards / Weak CPUs (`TinyPeripheral`):** Requires under `~1 KB` of RAM for the stateless `Utreexo` Merkle forest accumulator and runs up to `32` ultra-light AI cells.
- **Everyday Laptops & Desktop PCs (`StandardNode`):** Operates a living population of up to `512` Liquid Time-Constant micro-neural cells on standard CPU SIMD.
- **Workstations & GPU Servers (`ColossalOrganism`):** Batches up to `16,384` heterogeneous evolving cells simultaneously via 3D `TissueBatch` tensor kernels on `Metal` or `CUDA`.
