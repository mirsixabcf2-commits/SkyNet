## 面向全球普惠参与的最低硬件要求

SkyNet 彻底消除了中心化 AI 云平台与传统区块链强加的高昂硬件壁垒：
- **物联网传感器 / 嵌入式开发板 / 低功耗 CPU（`TinyPeripheral`）：** 无状态 `Utreexo` 默克尔森林累加器仅需不足 `~1 KB` 内存（RAM），即可同时运行多达 `32` 个超轻量 AI 微细胞。
- **日常笔记本电脑与台式机（`StandardNode`）：** 利用标准 CPU SIMD 指令集，即可驱动多达 `512` 个鲜活的液态时间常数（Liquid Time-Constant）微神经细胞种群。
- **工作站与 GPU 服务器（`ColossalOrganism`）：** 借助 `Metal` 或 `CUDA` 上的三维 `TissueBatch` 张量算子内核，可并行批处理多达 `16,384` 个异构进化细胞。
