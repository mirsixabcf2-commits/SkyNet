## Configuration Matérielle Minimale pour une Participation Mondiale Universelle

SkyNet élimine les barrières matérielles prohibitives imposées tant par les clouds d'IA centralisés que par les blockchains historiques :
- **Capteurs IoT / Cartes Embarquées / Processeurs Modestes (`TinyPeripheral`) :** Nécessite moins de `~1 KB` de RAM pour l'accumulateur de forêt de Merkle sans état `Utreexo` et exécute jusqu'à `32` cellules d'IA ultra-légères.
- **Ordinateurs Portables & PC de Bureau Courants (`StandardNode`) :** Fait vivre une population allant jusqu'à `512` micro-cellules neuronales à constante de temps liquide (Liquid Time-Constant) grâce aux instructions SIMD standard du CPU.
- **Stations de Travail & Serveurs GPU (`ColossalOrganism`) :** Traite par lots jusqu'à `16,384` cellules évolutives hétérogènes simultanément via des noyaux tensoriels 3D `TissueBatch` sur `Metal` ou `CUDA`.
