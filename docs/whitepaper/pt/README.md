## Requisitos Mínimos de Hardware para Participação Global Universal

O SkyNet elimina as barreiras proibitivas de hardware impostas tanto pelas nuvens centralizadas de IA quanto pelas blockchains legadas:
- **Sensores IoT / Placas Embarcadas / CPUs Modestas (`TinyPeripheral`):** Requer menos de `~1 KB` de RAM para o acumulador de floresta de Merkle `Utreexo` sem estado e executa até `32` células de IA ultraleves.
- **Notebooks Cotidianos e PCs de Mesa (`StandardNode`):** Opera uma população viva de até `512` células micro-neurais Liquid Time-Constant utilizando instruções SIMD padrão de CPU.
- **Estações de Trabalho e Servidores GPU (`ColossalOrganism`):** Processa em lote até `16,384` células heterogêneas em evolução simultânea por meio de kernels tensoriais 3D `TissueBatch` em `Metal` ou `CUDA`.
