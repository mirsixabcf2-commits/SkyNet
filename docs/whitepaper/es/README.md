## Requisitos Mínimos de Hardware para la Participación Universal Global

SkyNet elimina las prohibitivas barreras de hardware impuestas tanto por las nubes de IA centralizadas como por las cadenas de bloques heredadas:
- **Sensores IoT / Placas Embebidas / CPUs Modestas (`TinyPeripheral`):** Requiere menos de `~1 KB` de RAM para el acumulador de bosque de Merkle `Utreexo` sin estado y ejecuta hasta `32` células de IA ultraligeras.
- **Ordenadores Portátiles y PCs de Escritorio Cotidianos (`StandardNode`):** Opera una población viva de hasta `512` células micro-neuronales de Constante de Tiempo Líquida mediante instrucciones SIMD de CPU estándar.
- **Estaciones de Trabajo y Servidores GPU (`ColossalOrganism`):** Procesa por lotes hasta `16,384` células heterogéneas en evolución simultáneamente mediante núcleos tensoriales 3D `TissueBatch` sobre `Metal` o `CUDA`.
