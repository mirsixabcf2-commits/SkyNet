## Persyaratan Perangkat Keras Minimum untuk Partisipasi Global Universal

SkyNet menghapus hambatan perangkat keras yang membebani yang diberlakukan baik oleh komputasi awan AI terpusat maupun rantai blok (*blockchain*) warisan:
- **Sensor IoT / Papan Tertanam (*Embedded*) / CPU Lemah (`TinyPeripheral`):** Membutuhkan RAM di bawah `~1 KB` untuk akumulator hutan Merkle `Utreexo` tanpa status dan menjalankan hingga `32` sel AI ultra-ringan.
- **Laptop Harian & PC Desktop (`StandardNode`):** Mengoperasikan populasi hidup hingga `512` sel saraf mikro *Liquid Time-Constant* pada SIMD CPU standar.
- **Workstation & Server GPU (`ColossalOrganism`):** Memproses secara *batch* hingga `16,384` sel berevolusi yang heterogen secara simultan melalui kernel tensor 3D `TissueBatch` pada `Metal` atau `CUDA`.
